<p>I've spent years explaining the basics and nuances of <a href="https://blog.isquaredsoftware.com/2020/05/blogged-answers-a-mostly-complete-guide-to-react-rendering-behavior/">React's rendering behavior</a>. That post is by far the most widely read resource I've ever published, and it's helped thousands of React devs actually understand how React rendering actually works.</p>

<p>Now, we have the <a href="https://react.dev/learn/react-compiler/introduction">React Compiler</a>, which promises to &quot;automatically optimize your React apps&quot;. But how does it work? What is it doing to your components? and how does its behavior change our understanding of React's mental model?</p>

<p>This talk recaps the core fundamentals of React rendering, and then digs into the actual React Compiler rewritten component output to demystify how it works and how it optimizes React rendering performance. From there, we look at how this flips React's default rendering behavior upside down, and how that affects our own understanding of React.</p>
