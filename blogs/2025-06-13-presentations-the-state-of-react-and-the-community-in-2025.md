<p>I spend a lot of time reading (and participating in) discussions in the React community, across many different sites. Over the last few years I've seen an increasing amount of frustration and concerns from the community, questions about the motivations and intent behind React's development, and a growing disconnect between how the React team wants React to be used, and how the ecosystem is using React in practice.</p>

<p>I've put together this talk to explain and clarify what I'm seeing argued about. My goal is to answer questions, provide background context and explanation, highlight places where I'm seeing disconnects, and hopefully point out ways that things can be improved going forward.</p>
